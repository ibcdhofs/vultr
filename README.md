## Vultr 怎么收费：标价之外的真实账单

Vultr 的标价确实低：Cloud Compute 入门 $2.50/月（1 vCPU/0.5GB/10GB，仅 IPv6），含 IPv4 是 $3.50，真正「能用」的 1GB 内存档次 $5/月，High Performance 和 High Frequency 都是 $6/月起步。按小时计费，跑满一个月封顶在标价上。

但有几条藏在 FAQ 里的规则，直接影响它「便宜」的成色：

- **小时费率按 672 小时（28 天）折算**。也就是说第 28 天就跑满了全月价，不是按自然月 730 小时摊。$5 的机器跑 10 天约 $1.79，跑满一个月就是 $5。
- **$2.50 和 $3.50 档每账户分别限 2 台和 5 台，且不支持 API 自动化**，Terraform、脚本批量部署至少要 $5 档。
- **停机照常计费**，想停止扣钱只能销毁实例；而且 Cloud Compute 实例**只能升配不能降配**，配大了想退回来只能另开小机迁移。
- **附加费用叠起来不轻**：自动备份加收 20%（$5 变 $6），快照 $0.05/GB/月，DDoS 防护 $10/月/实例——比最便宜的整机还贵。
- **流量规则有小心思**：只算出站流量，每账户有 2TB/月的免费池化额度，实例自带的月流量配额按运行小时累积。举个例子，1TB/月套餐折算每小时约 1.48GB 额度，开机 2 小时跑了 20GB 就销毁，超出额度的 17GB+ 要按 $0.01/GB 单独计费。
- **不退款**。官方 FAQ 原话是「No, we do not offer refunds」，充值金额原则上不可退。目前的试用额度在 $200–$300 之间随活动浮动（$200 档 30 天内过期），新账户的出站 SMTP 端口还默认可能被封，要联系客服解封。

客观说，Vultr 也有搬瓦工给不了的东西：换 IP 销毁重开就行、按小时结算近乎零成本（搬瓦工是 $8.79/次，还有 15 天冷却期）；机房遍布五大洲，免费 Kubernetes 控制平面，还有 GPU 和裸金属产品线，Windows 系统也支持（只是价格偏高）。做海外业务、爬虫、临时测试环境，这套灵活性是实打实的。
